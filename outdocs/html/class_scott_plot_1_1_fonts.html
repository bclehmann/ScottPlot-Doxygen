static List< int > ScottPlot.Fonts.GetStandaloneCodePoints ( IEnumerable< List< int > > codePointLists)
inlinestatic

Take a list of code point lists as input. Each code point list must correspond to a single text element ("grapheme cluster"). Filter the list to retain the code point lists made up of single code points, i.e. remove combining characters, etc. Return as a flattened list of the remaining standalone code points.
