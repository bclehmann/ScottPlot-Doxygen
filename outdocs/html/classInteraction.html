Detailed Description

This class contains logic to perform plot manipulations in response to UI actions. To customize how user inputs are interpreted, inherit and override functions in this class. To customize behavior of actions, replace properties of Actions with custom delegates. To customize UI inputs, assign desired button and key properties of Inputs.
