\doxysubsection{Detailed Description}
A simple custom Y axis which includes a subtitle/sub-\/label. Note that \doxylink{class_scott_plot_1_1_axis_panels_1_1_experimental_1_1_left_axis_with_subtitle_ad00cb0567dbef505c86e8b3663ac22b4}{Measure} and \doxylink{class_scott_plot_1_1_axis_panels_1_1_experimental_1_1_left_axis_with_subtitle_a3bfb647a94ac22977a4300bf2d3a9444}{Render} are called whenever the plot needs to be rendered so be wary of heavy code that will slow down the rendering if you are using the chart in a user interface where there is zooming, panning, etc.
