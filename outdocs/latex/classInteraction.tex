This class contains logic to perform plot manipulations in response to UI actions. To customize how user inputs are interpreted, inherit and override functions in this class. To customize behavior of actions, replace properties of \mbox{\hyperlink{classInteraction_a7e00e6da534004ed32147695413c4591}{Actions}} with custom delegates. To customize UI inputs, assign desired button and key properties of \mbox{\hyperlink{classInteraction_aa9f42ce0622349d6e03e3410a4fccc3b}{Inputs}}.
