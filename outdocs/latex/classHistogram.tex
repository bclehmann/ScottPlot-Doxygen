Create a histogram which will count values supplied by \mbox{\hyperlink{classHistogram_aea23bf8724d9925e52cce6f40c4ae563}{Add(double)}} and \mbox{\hyperlink{classHistogram_a3e8b4fb9419a8c0dd90ec325e6ac490a}{Add\+Range(\+IEnumerable$<$double$>$)}} 


\begin{DoxyParams}{Parameters}
{\em min} & minimum value to be counted\\
\hline
{\em max} & maximum value to be counted\\
\hline
{\em bin\+Count} & number of bins between {\itshape min}  and {\itshape max} \\
\hline
{\em add\+Outliers\+To\+Edge\+Bins} & if false, outliers will not be counted\\
\hline
{\em add\+Final\+Bin} & if true, one more bin will be added so values equal to {\itshape max}  can be counted too\\
\hline
\end{DoxyParams}


If {\itshape min}  and {\itshape max}  are the same value, the {\itshape min}  and {\itshape max}  properties will be {\itshape min}  -\/ 0.\+5 and {\itshape max}  + 0.\+5, respectively. This is to handle an edge case where all values of an array are exactly the same, producing an identical min and max.
