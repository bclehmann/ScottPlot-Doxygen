An optional function to override where the intervals for ticks start. The Date\+Time argument provided is the start range of the axis (i.\+e. \doxylink{interface_scott_plot_1_1_i_axis_a47f2eb766c729705f03030dfaa603340}{IAxis.\+Min}). 

If omitted, the ticks will start from \doxylink{interface_scott_plot_1_1_i_axis_a47f2eb766c729705f03030dfaa603340}{IAxis.\+Min}. This may have undesirable effects when zooming and panning. If provided, the ticks will start from the returned Date\+Time. 

If the plot contains weekly data, and it is desired to have ticks on the 1st of each month\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{dt\ =>\ \textcolor{keyword}{new}\ DateTime(dt.Year,\ dt.Month,\ 1);}

\end{DoxyCode}
 If the plot contains hourly data, and it is desired to have ticks every 6 hours at 00\+:00, 6\+:00, 12\+:00, etc, then set \doxylink{class_scott_plot_1_1_tick_generators_1_1_date_time_fixed_interval_acd42a029a9d5d6f93a284baf1870d0e7}{Interval} to Hour, \doxylink{class_scott_plot_1_1_tick_generators_1_1_date_time_fixed_interval_a25a2cf2938ac60159209cbe0bea91b9b}{Intervals\+Per\+Tick} to 6, and provide the function\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{dt\ =>\ \textcolor{keyword}{new}\ DateTime(dt.Year,\ dt.Month,\ dt.Day);}
