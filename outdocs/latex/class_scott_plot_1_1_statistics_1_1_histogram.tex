\begin{DoxyParams}{Parameters}
{\em min} & minimum value to be counted\\
\hline
{\em max} & maximum value to be counted\\
\hline
{\em bin\+Count} & number of bins between {\itshape min}  and {\itshape max} \\
\hline
{\em add\+Outliers\+To\+Edge\+Bins} & if false, outliers will not be counted\\
\hline
{\em add\+Final\+Bin} & if true, one more bin will be added so values equal to {\itshape max}  can be counted too\\
\hline
\end{DoxyParams}

This is to handle an edge case where all values of an array are exactly the same, producing an identical min and max.
